## Test setup:
- One 2019 revision Maxon motor
	- Exact part number unknown, original out of production
- Diametric hand-placed on backside of motor
	- DigiKey [469-1024-ND](https://www.digikey.com/en/products/detail/radial-magnets-inc/8995/5126077?s=N4IgTCBcDaICwDYCcBaAjABjHFA5AIiALoC%2BQA)
- 3D printed temporary mount for above motor
- Spacing between motor mount and PCB set using hand-adjusted M3 screws
- 3.3 V supplied using external power
- Oscilloscope attached:
	- CH 1 (yellow): A
	- CH 2 (green): B
	- CH 3 (blue): I
- SPI pins set to unused configuration
	- $\overline{CS}$ (CSN) pulled up
	- CLK pulled low
	- MOSI pulled low
	- MISO left floating
- UVW pins set to unused configuration
	- All pins left floating

## Tests

#### 1. ABI Test - Clockwise
1. Set scope to trigger on CH 1 falling edge
2. Start spinning motor clockwise by hand
3. Capture single result while motor is spinning

###### Results
![[scope_0.png|697]]

- Datasheet's perspective is from the surface of the AS5047P package, looking up
- This matched the "counter-clockwise" waveform from the datasheet

#### 4. PWM Mode Test
1. Set scope to trigger on CH 3 rising edge
2. Move scope CH 3 to probe the W/PWM pin
3. Start spinning motor clockwise by hand
4. Observe behavior using scope and record observations

###### Results
- Output does not match PWM output, signals consistent with W channel from UVW mode
- Upon further datasheet review, PWM mode is disabled by default and **both** ABI and UVW are active by default (presumably unless PWM is enabled).
#### 5. Power Consumption Test
1. Using external power supply and multimeter, record current draw when motor (and magnet) is stationary.
2. Using external power supply and multimeter, record current draw when motor (and magnet) is rotating.
3. Lightly heat general area using a heat gun and observe record current draw when motor (and magnet) is stationary.

###### Results
- Current draw of $9.5 \pm 0.2\;mA$ when magnet is stationary.
- Current draw of $9.5 \pm 0.2\;mA$ when magnet is rotating (unchanged).
- Current draw of $\approx 10\;mA$ when heated.
## Key Results
1. When the datasheet references "clockwise" or "counter-clockwise", it is from the perspective of the package, normal to the board surface. When looking down upon the chip, the directions are reversed.
2. Both UVW and ABI are enabled as programmed from the factory. Unused UVW/ABI pins must be left floating to prevent damage to the chip.
3. $\approx 1.0\;mm$ of clearance between magnet surface and AS5047P is sufficient to provide a decent signal
4. Datasheet specified maximum current draw of $15\;mA$ is likely correct under expected conditions ($20 \degree C \le T_{A}\le125 \degree C$)
