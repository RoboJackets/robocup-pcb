RADIOBOARD2027_C_OVERHANG (30 x 40 mm, 4 layers) - OPEN ITEMS
Updated 2026-11-07. Only open items are listed. Design, lengths, rules and deviations: DESIGN_NOTES.md.
Interface: ../docs/INTERFACE.md. Firmware: ../docs/FIRMWARE.md. Bench map: docs/board_map.svg.
Current state: DRC 0 / 0 / 0 / 0 with parity, ERC 0, link matched 14.079 mm, USB matched in both orientations,
J2 mates the current controlboard J9 (20 / 20).


1. BEFORE ORDERING
------------------
1.1 Independent re-audit of the USB-skew changes (R5 / R6 moved, D+ A6 hop and its return via, D- trunk
    serpentine, VBUS L4 run into U4 pin 1, GND_L3_USB_HOP), then full DRC / ERC / parity (CLAUDE.md section 12).
1.2 Confirm the widths in the JLC impedance calculator for JLC04161H-3313: 0.15 mm link (target 50 ohm) and
    0.19 / 0.31 mm USB pair (target 90 ohm differential). If JLC reads low, use 0.18 / 0.32 mm. Order with
    impedance control.
1.3 Antenna (1U build): decide the 5 GHz gain question (FXP831 up to 7.24 dBi vs 3.65 dBi certified): cap 5 GHz
    TX power, 2.4 GHz only, or another antenna. Confirm the antenna has an MHF I plug.
1.4 Compare the stock KiCad USON-10 land (U2, U5, U6) with TI's DQA0010A land pattern.
1.5 Fab notes:
    - tent all vias (west pad-band vias and every via under the module body);
    - plug / fill and cap the 8 U1 EPAD gap vias (0.075 mm mask web to the paste openings);
    - J2 shield pins paste-in-hole, 2.00 mm B.Paste apertures, 0.13 mm stencil;
    - WROOM-1 build only: a stencil with no paste on U1 pads 30, 31, 32.
1.6 Parts: generate the BOM / CPL for this variant. Source U1, U4, J2 and ANT1 outside JLCPCB stock. Re-check
    stock of D1 (C5875754), D4 (C3702214), U7 (C1852117). Double-sided assembly.


2. BENCH BRING-UP
-----------------
2.1 Radio on USB, controlboard attached but unpowered: +3V3_HOST must stay below U7's VIT+ (2.93 V; expected
    <= 1.70 V) and EN must rise to about 3.2 V so the module leaves reset. If EN stays low, fit a small Schottky
    (BAT54 / RB521 class) in series with R2, cathode toward J2. Add a 10k bleeder on +3V3_HOST only if the rail
    exceeds the expectation.
2.2 Switchover: check the USB-to-host and host-to-USB transients at C1 (U7: rising 2.93-3.07 V, falling
    2.86-2.94 V).
2.3 Module supply at C1 during 5 GHz TX from a 3.30 V controlboard rail.
2.4 USB attach inrush on the team's laptops (exceeds the 10 uF limit; bench use only).
2.5 WROOM-1 build: RSSI and throughput against a devkit (antenna overhangs the front edge).
2.6 Mechanical: mate the U.FL before mounting the radio; check the cantilevered north-east corner and the
    standoff / screw-head clearances on the first assembly.


3. FIRMWARE (details in ../docs/FIRMWARE.md)
--------------------------------------------
3.1 ESP-Hosted SPI full duplex, set every pin explicitly: CLK GPIO6, MOSI GPIO7, MISO GPIO2, CS GPIO10,
    HANDSHAKE GPIO1, DATA_READY GPIO0, reset = EN. SPI mode 3.
3.2 Keep the RTC slow clock internal (GPIO0 / GPIO1 are also the 32 kHz crystal pins).
3.3 Keep MISO / HANDSHAKE / DATA_READY tri-stated while PWR_SRC_HOST (GPIO9) is low.
3.4 Keep the brownout detector on.
